# Symbols / 특수문자 (`divee.symbols`)

Keeps symbols that are hard to type on a Mac (□ ● → ※ …) in Divee's panel as chips — click one to copy it. Also adds a command that opens the macOS Character Viewer for emoji and more.
맥 키보드로 치기 어려운 기호(□ ● → ※ …)를 패널에 칩으로 두고 클릭 한 번에 복사해요. 이모지는 '이모지·기호 보기' 명령으로 macOS 문자 뷰어를 열어요.

- **Permissions / 권한:** none. Chips are copied by Divee itself when you click them.
- **Setting / 설정:** the symbol list (separated by spaces) — change it in Settings › Plugins, no code needed.

**It is already built into Divee** — you don't need to install it. To change it, download this folder, edit `main.js`, then Divee › Settings › Plugins › **Install from Folder…**. With the same `id`, yours wins over the built-in one.
**Divee 에 이미 들어 있어요** — 따로 설치할 필요 없어요. 고쳐 쓰고 싶으면 이 폴더를 받아 고친 뒤 '폴더에서 설치' 하세요. 같은 id 면 내 것이 이겨요.
